# Claude Code + 雷米埃尔桌宠 配置说明书

> 本包用于在一台全新的 Ubuntu 桌面系统(22.04 / 24.04,GNOME 环境)上,从零配置 Claude Code(走 DeepSeek 模型端点)和「雷米埃尔」桌面宠物。

> ⚠️ **安全说明:本包不包含任何密钥**,所有敏感位置均为占位符(`__DEEPSEEK_API_KEY__`、`__PET_DIR__`、`__USER__`)。安装前建议先把整个包备份一份(拷贝到 U 盘/网盘均可)。

---

## 一、包内容总览

```
Claude配置与桌宠包/
├── 说明书.md                        ← 本文件(从零安装指南)
├── install.sh                       ← 一键安装脚本(可代替手动步骤,推荐)
├── claude-config/
│   ├── settings.json                ← Claude Code 配置模板(界面/模型/自动压缩/桌宠联动钩子)
│   ├── env-claude.sh                ← DeepSeek 模型端点环境变量模板
│   └── settings.local.example.json  ← 权限白名单示例(仅 3 条,供参考格式)
└── remiel-pet/
    ├── remiel-pet-desktop.py        ← 桌宠主程序(Python/GTK3,透明无边框置顶窗口)
    ├── remiel-pet.html              ← 桌宠网页版(电子宠物模式,可用浏览器打开)
    ├── remiel-emotes/
    │   ├── remiel_1.gif             ← 待机表情
    │   ├── remiel_2.gif             ← 思考表情
    │   ├── remiel_3.gif             ← (备用,未使用)
    │   ├── remiel_4.gif             ← 运行表情
    │   └── remiel_5.gif             ← 成功表情
    └── .claude/
        └── settings.local.json      ← 可选:桌宠目录内的项目级权限模板
```

**工作原理**:每次启动 Claude Code 会话时,`settings.json` 中的 `SessionStart` 钩子自动启动桌宠;Claude 干活时,各事件钩子把状态写入 `/tmp/remiel-pet.state`(`idle`/`thinking`/`running`/`success`)和 `/tmp/remiel-pet.bubble`(气泡内容),桌宠每 300ms 轮询一次,切换表情、弹出气泡。

**本包不包含**(原因):
- API 密钥、代理密码 —— 安全考虑,一律占位符
- 原机器的完整权限白名单 —— 含代理密码和大量专用规则
- 桌宠窗口位置配置 —— 屏幕坐标随机器不同,程序会自动重建
- 会话历史 —— 属于个人记录

## 二、安装 Node.js 与 nvm

> 如果目标机器已经有 Node.js(≥ 20),可跳过本节。

1. 先更新软件源:

```bash
sudo apt update
```

2. 安装 nvm(Node 版本管理器):

```bash
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.3/install.sh | bash
```

3. 重新打开终端(或执行 `source ~/.bashrc`),验证:

```bash
nvm --version        # 预期输出类似 v0.40.3
```

4. 安装 Node(建议 26,与原配置一致):

```bash
nvm install node
node -v              # 预期输出 v26.x
npm -v               # 预期输出 10.x 或 11.x
```

## 三、安装 Claude Code

```bash
npm install -g @anthropic-ai/claude-code
claude --version     # 预期输出 2.x(比原机器版本新也没关系,不影响配置)
```

首次运行 `claude` 会引导初始化(选择主题等),直接回车接受默认即可,后面会用配置文件覆盖。

## 四、配置 DeepSeek 模型端点

Claude Code 默认连 Anthropic 官方 API,本配置改为走 **DeepSeek 的 Anthropic 兼容端点**,需要设置环境变量。

1. **获取 API 密钥**:登录 [platform.deepseek.com](https://platform.deepseek.com) → 「API Keys」→ 创建一个新密钥(以 `sk-` 开头)。

2. 打开 `claude-config/env-claude.sh`,把这一行的占位符换成你的密钥:

```bash
export ANTHROPIC_AUTH_TOKEN=__DEEPSEEK_API_KEY__   ← 换成 export ANTHROPIC_AUTH_TOKEN=sk-你申请的密钥
```

3. 把整个文件内容追加到 `~/.bashrc`(推荐用 install.sh 自动完成,手动的话):

```bash
cat env-claude.sh >> ~/.bashrc
source ~/.bashrc
```

4. 验证:

```bash
env | grep ANTHROPIC        # 应能看到 ANTHROPIC_BASE_URL 等变量
```

**各变量含义**:

| 变量 | 值 | 作用 |
|---|---|---|
| `ANTHROPIC_BASE_URL` | `https://api.deepseek.com/anthropic` | 把 Claude Code 的 API 请求指向 DeepSeek 兼容端点 |
| `ANTHROPIC_AUTH_TOKEN` | `sk-...` | DeepSeek API 密钥 |
| `ANTHROPIC_MODEL` | `deepseek-v4-flash` | 默认使用的模型 |
| `ANTHROPIC_DEFAULT_OPUS/SONNET/HAIKU_MODEL` | `deepseek-v4-flash` | 当代码请求 Opus/Sonnet/Haiku 时全部映射到该模型 |
| `CLAUDE_CODE_SUBAGENT_MODEL` | `deepseek-v4-flash` | 子代理(并行任务)使用的模型 |
| `CLAUDE_CODE_EFFORT_LEVEL` | `max` | 推理强度拉满,效果更好但更耗 token |
| `CLAUDE_AUTOCOMPACT_PCT_OVERRIDE` | `80` | 上下文用到 80% 时自动压缩(桌宠联动项) |

> ⚠️ 注意:`claude` 必须从**终端**启动才能读到这些环境变量;从桌面图标/文件管理器里启动不读 `.bashrc`。

## 六、复制桌宠文件夹

桌宠文件夹可以放在**任意位置、改成任意名字**——主程序通过自身路径定位表情和配置,不依赖固定路径。

```bash
mkdir -p ~/remiel-pet
cp -r <本包路径>/remiel-pet/. ~/remiel-pet/     # 注意末尾的 /. 会把隐藏文件(如 .claude/)一起复制
```

先手动试运行一次,确认桌宠能正常启动:

```bash
python3 ~/remiel-pet/remiel-pet-desktop.py
```

- 成功:屏幕右下角出现宠物窗口,终端打印 `[pet] 启动 ...` 信息
- 退出:窗口聚焦时按 `Q`,或右键宠物 → 「退出宠物」

## 七、应用 Claude 配置(settings.json 模板)

1. 打开 `claude-config/settings.json`,把占位符 `__PET_DIR__` 换成第六步的桌宠路径(只出现一次):

```bash
# 示例:直接替换占位符
sed -i "s|__PET_DIR__|$HOME/remiel-pet|g" claude-config/settings.json
```

2. 复制到 Claude Code 配置目录(如已存在先备份):

```bash
mkdir -p ~/.claude
[ -f ~/.claude/settings.json ] && cp ~/.claude/settings.json ~/.claude/settings.json.bak
cp claude-config/settings.json ~/.claude/settings.json
```

3. 校验 JSON 合法:

```bash
jq empty ~/.claude/settings.json && echo "配置 OK"
```

### 钩子逐条讲解(本配置的核心)

| 钩子事件 | 命令作用 |
|---|---|
| `SessionStart` ① | 写 `idle` 到状态文件、清空气泡文件——保证每次会话从干净状态开始 |
| `SessionStart` ② | 启动桌宠(`__PET_DIR__` 所在行);`|| true` 保证失败也不报错;`statusMessage` 让启动时显示「雷米埃尔正在呼唤你…」 |
| `UserPromptSubmit` | 你发消息时:状态 `thinking`,气泡显示 `think\|` |
| `PreToolUse` | Claude 调用工具时:状态 `running`,气泡显示 `run\|工具名\|命令或文件`(截断 90 字符) |
| `PostToolUse` | 工具执行完:如果是 Bash 显示退出码(`done\|Bash\|0`),其他工具显示 `done\|工具名\|ok` |
| `Stop` | 会话结束时:状态 `success`,气泡显示 `finish\|` |

所有钩子都是 `"async": true`(后台异步执行,不阻塞 Claude 工作)。钩子之间通过 `/tmp` 下的两个文件通信,不依赖任何个人路径,原样使用即可。

其余字段:`theme: dark` 深色主题;`model: deepseek-v4-flash` 默认模型;`autoCompactEnabled` + `env.CLAUDE_AUTOCOMPACT_PCT_OVERRIDE=80` 上下文超 80% 自动压缩。

### 状态 → 表情对照

| 状态文件内容 | 显示表情 |
|---|---|
| `idle` | remiel_1.gif(待机) |
| `thinking` | remiel_2.gif(思考) |
| `running` | remiel_4.gif(运行) |
| `success` | remiel_5.gif(成功) |

## 八、首次启动联调验收

按以下顺序逐项检查,确认桌宠与 Claude 联动正常:

| 步骤 | 操作 | 预期 |
|---|---|---|
| 1 | 终端运行 `claude` 开始会话 | 桌宠出现在右下角;`cat /tmp/remiel-pet.state` 输出 `idle` |
| 2 | 随便发一句消息(如「你好」) | 桌宠切到思考表情;`cat /tmp/remiel-pet.state` 输出 `thinking` |
| 3 | 让它执行一条命令(如「运行 `ls`」) | 桌宠切到运行表情;气泡显示 `run\|Bash\|ls ...` |
| 4 | 等命令执行完 | 气泡显示 `done\|Bash\|0`(0 是退出码) |
| 5 | `/exit` 结束会话 | 桌宠切到成功表情;气泡显示 `finish\|`;`pgrep -af remiel-pet-desktop.py` 确认进程仍在(桌宠不随会话退出) |
| 6 | 停止操作 30 秒 | thinking/running 状态自动回落到 `idle`(正常设计) |

> 小提示:会话结束后桌宠会一直留在屏幕上,重新开会话时它会被重复启动命令幂等处理(单实例锁),无需手动管理。

## 九、可选:恢复权限白名单

原机器的完整白名单(`~/.claude/settings.local.json`)**没有随包提供**,原因:
- 内含代理密码、Bearer token 等敏感信息
- 大部分规则是 OpenWrt 虚拟机调试专用,对新机器无用
- 包含 `Bash(cat)`、`Bash(python3 *)` 这类宽泛授权,盲目导入有风险

新机器上按需重建即可,两种方式:
1. **最省事**:正常使用 Claude Code,遇到权限询问时自己决定允许/拒绝,授权过的命令会自动累积进白名单
2. **参考格式**:照 `claude-config/settings.local.example.json` 的样子手动添加:

```json
{
  "permissions": {
    "allow": [
      "Bash(python3 *)",                          // 允许任意 python3 命令
      "Bash(pkill -f remiel-pet-desktop.py)",     // 允许关闭桌宠进程
      "Bash(jq *)"                                // 允许 jq 命令
    ]
  }
}
```

另有一份 `remiel-pet/.claude/settings.local.json`(桌宠目录内的**项目级**权限,含打开网页版桌宠等规则),仅当你在桌宠目录里开 Claude 会话时才有用。如需使用:把 `__PET_DIR__` 和 `__USER__` 占位符替换成实际值,再随桌宠目录复制(install.sh 加 `--with-project-perms` 参数会自动处理)。

## 十一、日常使用

**右键菜单**可调整(改动会自动保存到桌宠目录下的 `.remiel-pet-config.json`):
- 气泡:数量(1–10)、停留时间(3–20 秒)、形状(云朵/圆角矩形)、边框粗细与颜色、字号、文字颜色、背景色与透明度、间距
- 位置:停靠屏幕右/左
- 变换:旋转(0/90/180/270°)、水平/垂直镜像

**缩放**:鼠标滚轮,或按 `+` / `-`(范围 95–305 像素)

**移动**:按住左键拖动

**退出**:窗口聚焦时按 `Q` 或 `Esc`;右键菜单「退出宠物」;或 `pkill -f remiel-pet-desktop.py`

## 十二、故障排查

| 现象 | 排查步骤 |
|---|---|
| 桌宠不显示 | ① 手动前台运行 `python3 ~/remiel-pet/remiel-pet-desktop.py` 看报错;<br>② `ImportError: No module named gi` 等 → 第五步依赖没装全;<br>③ 在 SSH/无图形会话里启动必然失败(被 `|| true` 吞掉,属预期,桌宠只在图形桌面显示);<br>④ 脚本强制走 XWayland 以支持置顶,Wayland 桌面无需额外配置(Ubuntu 默认自带 XWayland);可用 `echo $XDG_SESSION_TYPE` 确认会话类型 |
| 气泡不更新/状态不变 | ① `jq --version` —— `PreToolUse`/`PostToolUse` 钩子依赖 jq,缺失时静默失败;<br>② `jq . ~/.claude/settings.json` 校验配置 JSON 合法;<br>③ `ls -l /tmp/remiel-pet.state` 确认文件存在;<br>④ 手动 `echo idle > /tmp/remiel-pet.state`,观察桌宠是否切换表情 |
| 桌宠位置跑出屏幕 | 删除桌宠目录下的 `.remiel-pet-config.json` 后重启桌宠(里面存的是旧屏幕的坐标,程序会重新以右下角为锚点,退出时再保存) |
| 状态一直 thinking/running | 30 秒无操作自动回落 idle,正常现象 |
| 中文气泡乱码 | `sudo apt install -y fonts-noto-cjk` 安装中文字体 |

## 十三、安全与卸载

**安全**:
- API 密钥只存在于两处:`~/.bashrc` 的 `### >>> claude-deepseek-env` 标记块内,以及 DeepSeek 官网账户里。包内永远是占位符
- 不要把含真实密钥的 `~/.bashrc` 或整个 `~/.claude` 目录发给别人
- 如需验证包内无泄漏:`grep -rn "sk-[A-Za-z0-9]\{20,\}" 包目录/`(匹配长密钥串)

**卸载**(彻底移除所有相关文件):

```bash
# 1. 移除 .bashrc 中的环境变量标记块
sed -i '/### >>> claude-deepseek-env/,/### <<< claude-deepseek-env/d' ~/.bashrc
# 2. 移除 Claude 配置(含桌宠钩子)
rm ~/.claude/settings.json
# 3. 关闭桌宠进程
pkill -f remiel-pet-desktop.py
# 4. 删除桌宠文件夹(可选)
rm -rf ~/remiel-pet
# 5. (可选)卸载 Claude Code
npm uninstall -g @anthropic-ai/claude-code
```

## 附录:install.sh 快速用法

```bash
bash <包路径>/install.sh                       # 交互式安装(会提示输入 API 密钥)
bash <包路径>/install.sh --api-key sk-xxxx     # 直接传入密钥,全程无人值守
bash <包路径>/install.sh --skip-apt            # 跳过依赖安装(已装过时)
bash <包路径>/install.sh --dir ~/pet           # 指定桌宠安装目录(默认 ~/remiel-pet)
bash <包路径>/install.sh --with-project-perms  # 同时安装项目级权限模板
```

脚本特性:幂等(重复执行不重复配置)、自动备份(覆盖前存 `.bak.<时间戳>`)、每一步打印中文进度。安装完按第八节验收即可。
